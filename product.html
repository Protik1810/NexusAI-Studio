💻 Direct Installation by Terminal

Install and launch NexusAI Studio instantly via terminal on Windows, Linux, and macOS.

🐧 Linux & 🍎 macOS (1-Line Terminal Install):
curl -fsSL https://raw.githubusercontent.com/Protik1810/NexusAI-Studio/main/install.sh | bash
🪟 Windows (winget Package Manager):
winget install https://github.com/Protik1810/NexusAI-Studio/releases/download/v1.0/NexusAI-Studio-Setup-1.0.0.exe
⚡ Cross-Platform Git & npm Run:
git clone https://github.com/Protik1810/NexusAI-Studio.git && cd NexusAI-Studio && npm install && npm run dev
